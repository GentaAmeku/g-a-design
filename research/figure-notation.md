# G.A Design — 図の記法(調査)

2026-08-31 / 対象: 流れの図(縦の連鎖・枝分かれ・合流) / 制約: 色を使わず形だけで種別を出す、依存ゼロ、白黒の紙で読める

## 結論

**A(輪郭で分ける)を採用。**種別4種を、箱の形そのもので出す。段=角丸長方形、分かれ目=六角形、外=破線の枠、保管=円筒。3案を同じ寸法・同じ図で組んで並べ、本人が選んだ(2026-08-31)。並べた実物は [figure-notation.html](figure-notation.html) にそのまま残してある。

決め手は**62% に縮めたときに差が残るか**。設計書は PDF で配って紙で読まれるので、A4 に載る実寸で読めないと意味がない。

## なぜ色ではなく形か

系列5色は明度を 61% で揃えてあるぶん、白黒にすると同じ灰色に潰れる(色どうしの明暗差は 1.00〜1.10)。だから「これは保管、これは外」のような**どれか1つを選ばせる情報は色に載せられない**。詳細は STYLE-GUIDE の「色は二重の手がかりに留める」。

この生成器は系列色を一切使わない。`.gad-node`(墨)・`.gad-link`(印の灰)・`.gad-arrow`(塗る印)の3つだけで描く。

## 並べた3案

同じ図(ノード7つ、枝3つ、合流あり)を、箱 176×48px・縦の間隔 44px・横の間隔 20px で固定したまま3通りに組んだ。

| 案 | どこに情報を載せるか | 段 | 分かれ目 | 外 | 保管 |
|---|---|---|---|---|---|
| **A 輪郭** | 箱の形そのもの | 角丸長方形 | 六角形 | 破線の枠 | 円筒 |
| B 枠の本数 | 枠線の引き方(外形は共通) | 実線1本 | 二重線 | 破線 | 上下に帯 |
| C 添える印 | 左辺に掛ける 12px の印 | 印なし | 塗った菱形 | 塗った三角 | 塗った二本帯 |

### 選ばなかった理由

**B(枠の本数)** — 4種とも寸法が完全に同じで、ラベル上限も揃い、版付けの分岐が要らない。実装は一番安い。落としたのは、**「二重線=分かれ目」「破線=外」が共通語彙ではない**から。図を見るたびに凡例へ戻ることになる。二重線が「強調」に読まれる問題もある。

**C(添える印)** — 箱が完全に同一なので、並べたときの列は一番整う。ラベル領域も削らない。落としたのは、**62% に縮めると 12px の印が 7.4px になり、ほぼ消える**から。遠目には4種とも同じ箱に見える。3案で一番弱かった。

### A の代償

- **六角形はラベルが 2 字幅ぶん狭い。**左右の尖り 14px×2 を引くので、内寸が 152px から 124px に落ちる。上限は 10 字幅ではなく 8 字幅。種別ごとに上限が違うのは煩わしいが、検査が数値で落とすので人が覚える必要はない
- **円筒は 176×48 の横長では「皿」に見える。**縦横比が 3.7 で、データベースの図で見慣れた縦長の円筒とは印象が違う。それでも「上に楕円が載った箱」は保管以外に読みようがないので、そのまま採った
- 描き分けが4通り要る。ただし一度書けば終わりで、以後は増えない

## ラベルの幅 — 実測して凍らせた

**箱が固定幅なので、ラベルが入るかどうかを機械で判定する必要がある。**生成のたびにブラウザで測るわけにはいかないので、送り幅を一度だけ実測して render.mjs に凍らせた。

測り方は書体選定([typeface.md](typeface.md))と同じ。Chrome で `canvas.measureText`、`font-size: 100px`、`Zen Kaku Gothic New` の 400。1文字を20回繰り返して測り、20で割って1文字あたりの送り幅を出した(端の丸めを均すため)。

### 分かったこと

**半角を一律 0.5 と数える手は使えない。**

| 文字 | 送り幅(em) |
|---|---|
| 全角(かな・漢字・全角記号) | 1.000 |
| `W` | 0.844 |
| `m` | 0.799 |
| `i` | 0.241 |
| `l` | 0.210 |
| 半角カナ(U+FF61〜FF9F) | 0.500 |

半角の幅は 0.21 から 0.84 まで4倍開く。半角20文字を 0.5 で数えると 10 字幅に見えるが、`W` を20個並べた実寸は 244.7px で、箱の内寸 152px から 92.7px はみ出す。逆に一律 0.9 で数えると `tokens.css を読む`(実寸 114.9px、余裕十分)が落ちる。**文字ごとの実測値を持つほかにない。**

`` ` ``(U+0060)の送り幅は 0 だった。この書体では合成用の記号として作られていて、幅を持たない。実測のまま 0 で入れてある。

### 単位

**1 字幅 = 全角1文字ぶんの送り = (1.000 + 0.03)em = 1.03em = 14.42px。**0.03em は本文の字間(`--gad-tracking`)で、CSS は最後の1文字の後ろにも足すので、文字数ぶんそのまま加算される。

上限は `step` / `outside` / `store` が 10 字幅(144.2px)、`branch` が 8 字幅(115.4px)。箱の内寸 152px と、六角形の内寸 124px に対して、それぞれ 7.8px と 8.6px の余裕がある。上限ちょうどのラベルを実際に組んで、文字の左右に 15.9px ずつ空くことを確かめてある。

## 寸法の決め方

箱の幅は、**3つ横に並べたときに本文の中へ収まる**ことから決まる。`.gad-figure-frame` の内寸は 590px(本文幅 640px − 枠 1px×2 − 内側の余白 24px×2)。横の間隔を 20px とすると、箱の幅の上限は (590 − 40) ÷ 3 = 183.3px。切りのよい 176px を採った(3つで 568px、22px の余裕)。

高さ 48px は、14px の1行に上下 17px ずつ。縦の間隔 44px は、矢印の頭 8px を置いても線が 36px 残る長さ。どちらも `--gad-gap-*` の段(44 / 22 / 14)から採ってある。
