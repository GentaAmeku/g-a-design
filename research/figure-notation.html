図の記法 — 候補3案

G.A Design / 2026-08-31 / 決めるのは「種別を形で出す語彙」

種別4種(段・分かれ目・外・保管)を、色を使わず形だけで出す。3案とも箱は 176×48px、縦の間隔 44px、横の間隔 20px で固定してある。使う class は .gad-node / .gad-link / .gad-arrow の3つだけで、SVG に色は書いていない。採用は A(輪郭)。2026-08-31 に本人が選んだ。この頁は、そのとき並べたものをそのまま残してある。

A 輪郭 — 採用

箱の形そのものを変える。フローチャートの共通語彙(六角・破線枠・円筒)を借りる。

遠目に一番効く。読み手が既に知っている形なので凡例が要らない。代わりに、六角形は左右の尖りぶんラベルが 2 字ぶん狭くなり、円筒は 176×48 の横長では「皿」に見える。

B 枠の本数

外形は角丸長方形ひとつに固定し、枠線の本数と実線・破線だけで分ける。

4種とも寸法が完全に同じで、ラベルの上限も同じ。版付けの分岐が要らない。代わりに「二重線=分かれ目」「破線=外」は共通語彙ではないので、初出の図に凡例か文が要る。

C 添える印

箱は4種とも同一。左辺に 12px の印を掛け、その印の形で分ける。

箱が完全に同じなので、並べたときの列が最も整う。印は塗り(--gad-mark)なので小さくても潰れない。代わりに、遠目には全部同じ箱に見え、印の意味は凡例なしには分からない。
